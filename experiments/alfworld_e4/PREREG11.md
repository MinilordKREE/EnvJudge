# PREREG11 — E4：成功轨迹的 regime 出身（frozen 2026-09-13）
材料：E3/E2 共享原环境 K=16 轨迹，seeds 0–29，不新增搜索 rollout。分组按共享 p̂₁₆：marginal (0, 0.2)、band [0.2, 0.8]、
saturated (0.8, 1]。臂 M / B / S / M+B，released single-success 归纳，两次归纳取均值，item 匹配到三者最小值（下限 4），
另加题数匹配子行（B、S 各抽 2 题 × 3 组）。评测与估计器同 E3-SL；N、placebo、O_all 复用。

预测
- E4-1（主）：item 匹配下，B > S 在 ID 或 OOD 上成立且 95% CI 不含 0。
- E4-2（问题本身）：item 匹配下，M ≥ B − 3 分（即稀有成功不差于带内成功）→ 记为"稀有成功同样有价值"；
  M < B − 3 且 CI 不含 0 → 记为"稀有成功较差"；其余记为"分不出"。
- E4-3：M+B > S，且 M+B ≥ O_all（后者点估计即可）。
- 全部臂对 N 与 placebo 的差作为标定同时报告。

对方法的后果（预先写死，避免事后解释）
- E4-2 判为"同样有价值"或"分不出" → 控制器的 skill 范式定义改为：p < 0.2 但估计阶段出现过成功的任务，保留并多采样，
  不送去开局；开局仍用于 p = 0 的任务。RL 范式的带定义不变（方差带 [0.2, 0.8]）。
- E4-2 判为"较差" → 现行定义不变，论文给出"成功的质量取决于其 regime"的机制解释。
- E4-1 不成立（B 不优于 S）→ 教学带在 skill 范式下没有下游依据，主表第二层的解释要相应收缩，并在论文中明说。
预算 ≤ USD 40（归纳 ≈ 2；评测 8 条件 × 2 归纳 × 3 seed × 274 ≈ 35）。
