# PREREG6 is superseded (owner decision, 2026-09-07)

`PREREG6.md` was frozen from an earlier E1-SL brief and conflicts with the v2 spec (`docs/spec/AEA_v2.md`)
in five places: LLM-proposed knobs, hand-off kept out of the main bank, no A ≤ R total-rollout constraint,
K16 confirmation never written back, and the unified acceptance rule with the two bands B_T / B_L.
No rollout was ever run under PREREG6. No experiment may start under it; the E1-SL phase files
PREREG7 from the v2 spec. The original text is kept unchanged for the record.
