# aea v0.2 module map (method of record: docs/spec/AEA_v0.2.md)

| module | box element | notes |
|---|---|---|
| `aea/config.py` | six method constants + `impl` | `AEAConfig(band_t, band_l, k, accept, probe, cap, impl=ImplConfig(...))`; hash into every manifest |
| `aea/estimate.py` | `estimate(policy, E)` | unchanged Beta estimator; K = 16 with early stop; batch schedule and confidence in `impl` |
| `aea/evaluate.py` | `evaluate(env)` | the one 4 → 8 rule; `in_band` iff 3–5 of 8 |
| `aea/bracket.py` | the bisection | `[lo, hi]` after the d = 1 test; ≤ `impl.max_bisections`; order-violation stop |
| `aea/families.py` | families, proposer, leverage | library (FooterMask, HorizonSqueeze), `propose_families` under the dose contract, `LeverageTable` (rate, ordering, start dose) |
| `aea/witness.py` | `solvable()` | asymmetric guard: policy replay → oracle → uncertified / self-certify |
| `aea/session.py` | (glue) | sessions on the released harness stack, replay, oracle; never charged |
| `aea/stage.py` | stage candidates | end + midpoint of 3 failed rollouts, compile, dedupe, ≤ 6, latest first, guarded |
| `aea/budget.py` | the one budget | `search` with the hard cap; refunds for errored rollouts |
| `aea/controller.py` | the loop | keep / harden / stage; outcomes `accepted / kept / dropped(reason)`; resume re-runs `infra_error` |
| `aea/io.py`, `aea/substrate.py`, `aea/runner.py`, `aea/llm/*`, `aea/core/*`, `aea/evalhook.py`, `aea/evaldriver.py` | engineering (unchanged rigor) | ledger, manifest, guards, attribution, resumability, corpus/trace formats |
| `aea/controller.py` task pool, `aea/session.py` `SESSION_LOCK` | engineering (wall clock only) | `run(tasks, concurrency=n)`: in-process sessions (harden replay/oracle, stage oracle, prefix compilation, fidelity check, game-file lookup) serialized under the one process lock, rollouts overlap; harden of task *i* waits for tasks < *i* (leverage prior = sequential state); `corpus.jsonl` / `accounting.csv` written in task order (byte-identical to sequential); pool size in `events.jsonl` `run_start` and, by the driver, in `manifest.json` `extra.concurrency` (`tasks`, `rollouts`, `inflight_episodes` <= 16) |
| `scripts/handoff_demos.py` | extension (not the method) | hand-off demonstrations for dropped zero tasks |
| `docs/legacy/` | removed | Displacement family and builder, v0.1 integration tests |
| `scripts/v0_1/` | frozen | Round 1 / 1b / E2 step-1 protocol scripts (run against tag `aea-v0.1`) |

Outcome reasons: `no_leverage` (no family had leverage at d = 1), `exhausted` (a family's bracket ended
without an in-band dose or on an order violation), `dead` (every probed state 0 of 4), `too_easy`
(a probed state 4 of 4 and none in band), `uncertified` (no candidate passed the guard),
`budget` (the cap ended the task), `no_failed_rollout` (a zero task without a usable failure).
